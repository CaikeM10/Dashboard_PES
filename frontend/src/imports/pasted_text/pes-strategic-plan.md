Crie o design de uma aplicação web completa para monitoramento do Planejamento Estratégico da Educação (PES), voltado para gestão pública e acompanhamento de metas educacionais.

O sistema deve substituir relatórios manuais por uma plataforma digital interativa com dashboards estratégicos, acompanhamento contínuo e geração de relatórios.

Estrutura do Sistema

O sistema deve possuir as seguintes telas:

Login
Dashboard Estratégico
Desafios
Objetivos Estratégicos
Entregas
Metas
Atualizações
Relatórios
Administração (Escolas e Alunos)

Hierarquia do Sistema

O sistema deve seguir a seguinte estrutura:

Desafios
→ Objetivos
→ Entregas
→ Metas

Essa hierarquia deve ser visualmente clara no sistema.

Dashboard Estratégico

Criar um dashboard executivo contendo:

Progresso geral do planejamento
Cards de indicadores:

Total de Metas
Metas Concluídas
Metas em Andamento
Metas Atrasadas

Os cards devem ser clicáveis e redirecionar para páginas filtradas.

Adicionar:

Gráfico de progresso por objetivo (clicável)

Radar estratégico

Mapa estratégico (com relação entre objetivos)

Timeline de execução das metas

Seção:

"Objetivos que precisam de atenção"

Página de Metas

Cada meta deve conter:

descrição
objetivo
entrega vinculada
responsável
prazo
progresso
status
última atualização

Adicionar:

Observações contínuas
Histórico de atualizações
Campo de motivo de atraso (obrigatório quando atrasado)

Encerramento de Meta

Criar funcionalidade de fechamento da meta com:

status final:

concluída
não concluída
adiada

justificativa final
avaliação da execução
data de encerramento

Ações dentro da Meta

Permitir adicionar ações dentro da meta:

descrição da ação
responsável
prazo
status

Página de Objetivos

Adicionar:

campo de observações
status visual (verde, amarelo, vermelho)

Atualizações

Criar timeline contendo:

meta
responsável
percentual anterior
novo percentual
data
observação

Relatórios

Permitir exportação:

PDF (resumo executivo)
Excel (dados detalhados)

Módulo Administrativo

Criar área exclusiva para administrador contendo:

listagem de escolas
dados dos alunos
status geral

Essa área deve ser separada do painel principal.

Filtros

Adicionar filtros em todas as listas:

objetivo
status
responsável
prazo

Estilo Visual

Design institucional moderno com:

sidebar
cards
gráficos
tabelas
cores neutras

Indicadores com cores:

verde (ok)
amarelo (atenção)
vermelho (crítico)

Experiência do Usuário

O sistema deve permitir:

navegação rápida
visualização clara de indicadores
interação com dados (cliques e filtros)
facilidade de atualização

Resultado Esperado

O design final deve parecer um sistema profissional de gestão pública, semelhante a plataformas de monitoramento estratégico utilizadas por governos.
