Crie o design de uma aplicação web completa para monitoramento do Planejamento Estratégico da Educação (PES).

O sistema deve substituir relatórios estáticos (PowerPoint ou Excel) por um dashboard digital interativo, permitindo acompanhar objetivos estratégicos, metas e progresso das ações em tempo real.

O design deve seguir o padrão de plataformas modernas de gestão pública e dashboards de business intelligence, com layout profissional, organizado e orientado à tomada de decisão.

O sistema será utilizado por Secretarias de Educação e gestores públicos.

Estrutura geral do sistema

O sistema deve possuir as seguintes telas principais:

Login

Dashboard Estratégico

Objetivos Estratégicos

Metas

Atualizações de Progresso

Relatórios

A interface deve usar um layout administrativo moderno com sidebar lateral e área principal de conteúdo.

logotipo da secretaria

título do sistema:
Sistema de Monitoramento do Planejamento Estratégico

campo de email

campo de senha

botão de entrar

Visual limpo e institucional.

Design inspirado em dashboards de gestão pública.

Dashboard Estratégico

Criar um dashboard executivo de gestão estratégica.

O dashboard deve apresentar:

Progresso geral do planejamento estratégico.

Cards de indicadores:

Total de Metas
Metas Concluídas
Metas em Andamento
Metas Atrasadas

Esses cards devem ser clicáveis, redirecionando para a página de metas com filtros automáticos.

Exemplo:

Total de Metas → mostra todas as metas
Metas Concluídas → filtra metas concluídas
Metas em Andamento → filtra metas em andamento
Metas Atrasadas → filtra metas atrasadas

Adicionar efeito hover e indicar interatividade.

Gráfico de Progresso por Objetivo

Adicionar um gráfico mostrando o progresso de cada objetivo estratégico.

Cada barra representa um objetivo.

O gráfico deve permitir drill-down.

Ao clicar em um objetivo, o sistema abre a lista de metas vinculadas.

Radar Estratégico

Adicionar um gráfico radar de desempenho estratégico.

Cada eixo representa um objetivo estratégico.

O radar mostra o progresso percentual de cada objetivo.

Isso permite identificar rapidamente áreas com menor desempenho.

Mapa Estratégico

Criar uma seção visual chamada Mapa Estratégico do Plano.

O mapa deve mostrar os objetivos estratégicos conectados entre si, demonstrando relação de causa e efeito.

Os objetivos devem aparecer em blocos conectados por setas.

Cada bloco deve mostrar:

nome do objetivo
percentual de execução
status visual

Cores:

verde → objetivo atingido
amarelo → atenção
vermelho → risco

Objetivos que Precisam de Atenção

Adicionar uma seção no dashboard chamada:

Objetivos que precisam de atenção

Listar automaticamente os objetivos com menor progresso.

Isso ajuda gestores a identificar prioridades estratégicas.
